Publish Messages

How it works: create one publish profile for each MQTT message. A profile defines the topic, when to send, and the payload. You can group several Modbus values in one JSON message or publish a single value.

RS485 & Modbus

Configure RS485 services and Modbus devices. Gateway mode supports the common FC01/02/03/04 read and FC05/06/0F/10 write operations; Data Points define scheduled reads only.

Modbus Devices & Data Points

Supported Modbus function codes
Read / polling
FC01 Read CoilsSupported
FC02 Read Discrete InputsSupported
FC03 Read Holding RegistersSupported
FC04 Read Input RegistersSupported
Write / gateway forwarding
FC05 Write Single CoilSupported
FC06 Write Single RegisterSupported
FC0F Write Multiple CoilsSupported
FC10 Write Multiple RegistersSupported
Data Points are scheduled reads. Therefore the Data Point table uses FC01–FC04 only. FC05/FC06/FC0F/FC10 are write commands and are handled by the Modbus TCP ↔ RTU Gateway when Access Mode = Read & Write.
